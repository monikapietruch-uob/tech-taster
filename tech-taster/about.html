About this prototype

This is version 1 of a prototype, made in November 2026 by a tutor on the foundation tech pathway at the University of Bedfordshire. It is for discussion. It is not an official university page, and nothing on it is a promise about courses or entry.

What it is for

Some people never apply for a tech course because they have decided they could not do it. This taster gives them ten minutes to find out, in private, with no sign-up.

Accessibility

The aim is to meet the Web Content Accessibility Guidelines (WCAG) 2.2 at level AA. This version was built with that aim, but it has not yet been tested by people who use assistive technology. Treat the list below as intentions that still need checking.

  • Everything works with a keyboard. The Tab key always moves on, so the code box cannot trap you.
  • The picture of the world has a description in words underneath it, which changes when the robot moves.
  • Results are written in words, not only shown in colour, and a screen reader is told when a result changes.
  • Text and controls have been checked for colour contrast, and every button is large enough to tap.
  • There are no time limits. If your device is set to reduce motion, the robot moves without gliding.
  • You never have to type. The Add buttons build the program for you.

Not yet done: testing with screen readers, testing in more browsers, and captions for the videos that are planned.

Privacy

  • There is no sign-up, and there are no cookies, adverts or tracking.
  • Your progress and your programs are saved in your own browser, so you can carry on later. They are not sent anywhere. Clearing your browser data removes them.
  • When the site is on GitHub Pages, GitHub, like any web host, may log technical details such as IP addresses when a page is requested.
